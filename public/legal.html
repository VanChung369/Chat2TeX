Chat2TeX legal & privacy

Local processing

Conversation text, images, LaTeX source, compiler logs, PDFs, and ZIP files are processed locally in the extension. Chat2TeX adds no analytics and does not upload those contents to a compilation server.

Compiler downloads

The extension downloads pinned compiler files from GitHub release hosting. When a required TeX Live file is missing, it requests only an allowed numeric format and static filename from texlive2026.texlyre.org. Those services can observe normal request metadata such as IP address, user agent, and requested filename; requests contain no conversation or generated output.

Local cache

Verified compiler/package files and integrity metadata are cached locally. Clear cache removes cached bytes, negative lookups, and the first-seen package hash ledger; the next PDF export downloads required files again.
